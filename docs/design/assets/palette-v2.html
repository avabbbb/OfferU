规则

  1. 中性色 ≈ 90%，墨黑 ≈ 8%，橙/紫 ≤ 2% （Figma 60/30/10 的克制版）
  2. 蓝色退出品牌，只留作「已投递」状态色
  3. 侧栏 = N2，画布 = N1，内容 = 白；靠层级区分，不换色相
  4. 颜色永远配文字或图标，不单靠颜色表达状态
