# OfferU 产品需求

> 2026-11 重写。旧版在 [archive/prd-2026-10](./archive/prd-2026-10/PRD.md)，只作参考。

## 1. 一句话

开源、本地优先的校招求职工作台：把岗位收进来、按档案排好先后、按 JD 改好简历、写好网申和邮件、盯住面试进度、面完复盘再写回档案。数据在自己电脑上，模型和 Agent 用自己的。

第一批用户：会用 AI 的应届生和实习生。

## 2. 核心闭环

```text
收集岗位 → 评估排名 → 按 JD 定制简历 → 投递（官网 L1 对话 / 邮件草稿）→ 面试看板 → 复盘写回档案
                        ↑                                                        │
                        └────────────────── 档案（profile + 职业记忆）←─────────────────┘
```

档案是中心：评估、定制简历、L1 回答都读它，复盘往里写。每一环的产出都挂在同一个岗位下面，下一环直接拿来用，不用手动复制。

## 3. 原则

| 原则 | 意思 |
| --- | --- |
| 本地优先 | 数据在本机 SQLite，不上传、不注册。 |
| Agent 直接写，能撤销 | 改档案、改岗位、加待办直接生效，进「最近改动」，一键撤销。 |
| 对外的事要点头 | 发邮件、提交网申、批量删除由用户点。Agent 只写草稿。 |
| 不编造 | 简历和回答里的经历都要在档案里有依据，没有就问或标「无依据」。 |
| 不绑模型 | 内置 Agent 用设置里的 OpenAI 兼容接口；外置 Agent（Codex / Claude Code 等）走 MCP。写草稿交给「当前选中的 Agent」。 |
| 不碰风控 | 不后台爬 BOSS / 小红书，不绕反爬。这类页面只通过用户在自己浏览器里点插件「存为岗位」。 |

## 4. 功能

### 4.1 岗位收集

- 插件「存为岗位」（主入口）：任何页面，只读当前页，选中文字优先当 JD。
- 网页「贴链接或 JD」一个框：链接用 fetch_page 解析公开页；抓不到就提示用插件或贴 JD，不存空壳。贴 JD 文本由内置 Agent 拆出公司、岗位、城市、截止、投递方式。
- 手动添加折叠起来，留给内推。

**验收**：飞书招聘详情页贴链接，公司、岗位、JD 自动填好；列表里公司和岗位名都显示。

### 4.2 评估排名

- 读档案和偏好（方向、城市、公司类型），给每个岗位打 0–100 分并写三句理由（匹配点、短板、建议），存在岗位上。
- 岗位列表可按分排序；一键「评估未评估的」。
- 以后：每天按关键词从公开官网拉岗位、自动排名，前 N 个备好投递包，用户逐个点头。

**验收**：有档案和 3 个岗位时点评估，每个岗位出现分数和理由，理由引用的经历在档案里。

### 4.3 按 JD 定制简历

- 岗位详情页一键定制：复制主简历、挂到这个岗位下、按 JD 改写，可撤销。编辑器左写右看，导出 PDF。

**验收**：定制后详情页出现新简历，经历都能在档案里找到，撤销后消失。

### 4.4 投递

- **官网 L1**：从岗位进入对话，整页粘贴网申题目，按档案 + JD + 定制简历逐题回答；每条回答单独复制、可要多个版本；新经历一键存进档案。对话存成岗位下的 doc，下次接着聊。
- **邮件投递**（小红书等）：从 JD 里拆出邮箱和标题 / 附件要求，生成邮件草稿 + 定制简历 PDF。用户点「发送」才发。
- 插件 L2 自动填表往后放。

**验收**：贴一段真实网申题，每题有可复制的回答；小红书岗位生成的邮件收件人和标题符合帖子要求。

### 4.5 面试看板与复盘

- 看板放在今天页，按状态分列（想投 / 已投递 / 笔试测评 / 面试中 / offer），「已结束」（未通过、不投了）默认收起；拖动改状态，卡片显示分数和下一件事的时间。岗位卡片可加标签（行内 #标签 灰字），看板顶上按标签筛选。邮箱同步识别到的回执和邀约自动推动状态。
- 复盘：面完写下问了什么，Agent 提炼「下次要补的」，新经历和好的回答一键存进档案。

**验收**：拖动卡片状态变化并可撤销；给岗位加标签后能按标签筛出来；复盘里一条新经历存进档案后，下次定制简历能用到。

### 4.6 入口

- 打开时只给一个「下一步」（规则判断）。开局三问先不做。
- Ctrl+K 内置 Agent；外置 Agent 通过 MCP 用同一套工具。

## 5. 不做

- 自动提交网申、自动打招呼、绕反爬、伪造请求。
- 桌宠、开局三问、统计报表。
- 线上版 / 云同步 / 账号体系（核心闭环打磨好之后再说）。

## 6. 成功标准

一个岗位走完全程：存岗位 → 看到分数和理由 → 一键定制简历 → L1 回答或邮件草稿 → 看板推进 → 复盘写回档案，全程不离开 OfferU、不手动复制档案。
