# OfferU 产品需求（PRD）

> 2026-10 重写。旧版设计见 [archive/pre-2026-11](./archive/pre-2026-11/)，只作参考。

## 1. 一句话

**OfferU 帮校招生和实习生把几十家公司的网申、笔试、面试管住：今天该做什么、每个岗位走到哪了、官网表单怎么填、面完怎么复盘。** 数据都在自己电脑上，AI 可以是内置的小模型，也可以是你已经在用的 Codex / Claude Code。

## 2. 用户和场景

**目标用户**：国内应届生（秋招 / 春招）和找实习的在校生。

典型的一周：

- 同时盯 30–100 个岗位，大部分在公司官网网申（北森、Moka、飞书招聘等），每家表单都要重填一遍教育、实习、项目和「你为什么想来」。
- 截止日期、测评链接、笔试和面试时间散落在邮件、短信和群里，经常错过。
- 简历要按岗位改，但改着改着就跟真实经历对不上了。
- 面完就忘了问过什么，下一轮还在同一个地方卡住。

## 3. 要解决的问题，按优先级

1. **不漏事**：截止、测评、笔试、面试都在一个地方，打开就知道今天做什么。
2. **少重填**：经历只说一次，网申表单、简历、自我介绍都从同一份档案里取。
3. **不编造**：AI 写的每句话都要能在档案里找到依据；找不到就留空或者问你。
4. **能接着上次做**：对话、改动、复盘都存下来，换个 Agent 也能接着干。

## 4. 产品原则

| 原则 | 具体意思 |
| --- | --- |
| 本地优先 | 数据存在本机一个 SQLite 文件里，不上传，不需要注册。 |
| Agent 直接写，能撤销 | AI 改档案、改岗位、加待办都直接生效，全部写进「最近改动」，一键撤销。不搞「AI 提议 → 你审核」那套确认。 |
| 对外的事要点头 | 只有发出去的东西需要你点：提交网申、发邮件、给 HR 打招呼，以及批量删除。 |
| 不绑模型 | 不提供模型 key。内置 Agent 用你在设置里填的 OpenAI 兼容接口；外置 Agent 用你自己的 Codex / Claude Code。两者都没有时，所有手动功能照样能用。 |
| 少即是多 | 一个页面一件事，没有统计卡、徽章、引导弹窗。界面学 Apple / Notion：安静、留白、黑白灰。 |

## 5. 不做的事

- 海投、自动打招呼、云手机、绕过反爬、伪造请求头。
- 邮箱接入、BOSS 直聘、统计报表、插件市场、姿态 / 表情面试分析。
- 未经同意收集对话或上传数据。
- 多人协作、账号体系、云同步（以后再说）。

## 6. 功能范围

一级导航只有 5 个：**今天 · 岗位 · 简历 · 面试 · 设置**。另外有两个随处可用的入口：**Ctrl+K 输入框**和**浏览器插件**。

### 6.1 今天

打开 OfferU 第一眼看到的页面。

- 顶部一句「下一步」，**用规则判断，不调用 AI**。按顺序：有逾期的事 → 两天内有笔试 / 面试 → 没有档案 → 没有简历 → 还没有岗位 → 有想投但没投的 → 投了 7 天没动静。
- 待办按「逾期 / 今天 / 7 天内 / 以后 / 没定时间」分组，可以勾掉，可以直接加一条。
- 「最近改动」：谁（你 / 内置 Agent / codex / claude）在什么时候改了什么，每条都能撤销。

**验收**：空数据目录下打开今天页，看到「先建档案」；加一条明天的面试，下一步变成「准备 xx 面试」；勾掉待办后最近改动多一条，撤销后待办恢复。

### 6.2 岗位

- 列表：公司、岗位、状态、截止日期。状态只有 7 个：想投 / 已投递 / 笔试测评 / 面试中 / offer / 未通过 / 已结束。
- 添加岗位：贴链接（自动抓公开页面的文字）或者手填。
- 岗位详情：JD、备注、这个岗位的待办和日程、这个岗位的文档（定制简历、网申对话、面试复盘）。

**验收**：贴一个公开的招聘链接，岗位标题和 JD 自动填好；在详情页改状态，列表和今天页同步变化。

### 6.3 档案和简历

- **档案**：基本信息一份（姓名、学校、专业、毕业年份、联系方式、求职方向），加上一条条「职业记忆」：实习、项目、教育、技能、奖项、偏好。每条记忆写具体的事、数字和用户原话。
- **简历**：存成 Markdown + 模板名，先做 3 套模板：单栏、紧凑、带照片。一份主简历，加上按岗位定制的版本。左边写，右边实时预览，一键导出 PDF。
- 导入旧简历（PDF / Word）：先把原文存进档案，再由 Agent 拆成一条条记忆（PR2 用 Codex，PR3 起 Ctrl+K 助手自动拆）。
- 从档案生成主简历：不调用 AI，按固定顺序把档案拼成 Markdown，之后自己改或让 Agent 改。
- 定制简历：Agent 读 JD 和档案，复制一份主简历改，挂到这个岗位下面，改了哪里在最近改动里能看到、能撤销。

**验收**：导入一份 PDF 简历，原文进入档案，Agent 能把它拆成教育、实习、项目；导出的 PDF 中文不乱码、一页内排版正常；让 Agent 按某岗位定制，岗位详情里出现新简历，撤销后消失。

### 6.4 官网投递助手

网申最费时间的是开放题和重复字段。

- 在岗位里打开「网申」：把官网表单的题目贴进来（或者由插件读出来），Agent 按档案逐题回答，每个回答是一个可复制的块。
- 对话存成这个岗位的一份文档，下次打开接着聊；同一题可以要多个版本。
- 回答里出现档案里没有的新事实，可以一键「存进档案」。
- 第四期（PR4，排在清理之前）：浏览器插件在已适配的网申系统（北森、Moka、飞书等）上自动读页面，每个输入框旁边出现「填写」，悬停预览，已有内容时变成「替换」，可以撤销。**提交按钮永远由用户自己点。**

**验收**：贴一段真实的网申题目，每题都有回答，回答里的经历都能在档案里找到；关掉再打开，对话还在。

### 6.5 面试

- 准备：按岗位和轮次，Agent 根据 JD 和档案列出可能被问的问题和你可以讲的经历。
- 复盘：面完写下（或口述后粘贴）问了什么、答得怎样，存成这个岗位的一份复盘文档；Agent 提炼出「下次要补的」，变成待办或档案里的记忆。

**验收**：写一段复盘，岗位详情里出现复盘文档，今天页出现对应的待办。

### 6.6 Ctrl+K 和 Agent

- **Ctrl+K**：任何页面按下，输入一句话，比如「字节明天下午 3 点二面」「把我简历按这个岗位改一下」。内置 Agent 用同一套工具处理，最多 6 步；结果写进最近改动。
- **大活交给后台 Codex**：内置 Agent 判断是长任务（定制简历、调研公司、整理一堆经历）时，交给后台 Codex 跑，完成后结果出现在最近改动里。
- **外置 Agent**：Codex / Claude Code 通过 MCP 连接 OfferU，用的是同一套工具，读写同一份数据。`offeru connect` 一条命令完成注册。

**验收**：在设置里填好模型后，Ctrl+K 输入「腾讯 PCG 后端，下周一截止」，岗位和截止日期都建好；在 Codex 里说「看下我今天要干嘛」，回答和今天页一致。

### 6.7 桌面小球（第四期之后）

`offeru start` 时打开一个小窗：奶娃头像，有新事情时动一下，悬停显示今天的待办，可以直接勾掉。

## 7. 成功标准

只看主线能不能走通，不看测试数量。

1. **装好就能用**：一台新电脑，从安装到看到今天页不超过 5 分钟，不需要装 Python / Node。
2. **一个岗位走完全程**：添加岗位 → 定制简历 → 网申回答 → 投递 → 面试 → 复盘，全程不离开 OfferU，也不需要手动复制档案内容。
3. **两个 Agent 一份数据**：内置 Agent 和 Codex 做的改动都出现在最近改动里，都能撤销。
4. **不编造**：网申回答和定制简历里的每段经历都能在档案里找到依据。

## 8. 还没定的问题

- 桌面小球勾掉待办时，是否同时推进投递状态（比如勾掉「投递腾讯」→ 腾讯变成已投递）？做到小球时再定。
- 后台 Codex 能否无人值守运行（`codex exec` 的权限和沙箱），要在 PR5 前先验证。
