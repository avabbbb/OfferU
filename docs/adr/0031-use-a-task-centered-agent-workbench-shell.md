# 采用任务中心的 Agent 工作台外壳

OfferU 的 WebUI 采用受 Codex 启发的任务中心外壳：使用者可以从求职流程和近期求职任务进入当前工作，并在需要时查看状态、证据、审批与结果。Codex 只提供外壳参考；岗位数据库、属性与侧边预览等数据工作方式借鉴 Notion，投递阶段与时间线、岗位研究、简历编辑与预览、日程和面试训练继续使用 OfferU 自己的领域界面。对象详情与主 Agent 共用一个右侧上下文栏，在“详情”和“OfferU”两种模式之间切换并共享当前选中对象，同一时间只显示一种模式；不保留会遮挡内容、形成第二套状态的悬浮机器人。岗位、投递、日程和求职任务统一采用“列表 → 右侧检查器 → 复杂编辑全屏”的渐进披露路径，不把所有业务界面改造成聊天记录，也不因此合并现有领域会话或事实模型。简历深度编辑和面试房间自动进入专注模式，收起全局导航与检查器，只保留返回、任务状态和召回主 Agent 的最小控制条。WebUI 使用 `Ctrl+K` 统一搜索、跳转和注册操作；操作员 TUI 保持斜杠 Skill、键盘与文本优先的呈现方式。WebUI 与操作员 TUI 只在交互呈现上分化，仍通过同一 Operation Registry 共享能力、权限、确认、审计、数据授权和错误语义。
