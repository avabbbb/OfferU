# 使用条目级变更账本演进使用者职业模型

OfferU 的单一长期职业模型由职业模型变更账本中仍有效的条目派生，面向具体岗位只生成岗位职业投影，不按 JD 改写主模型。职业证据必须经使用者确认；使用者明确陈述的求职偏好视为已经确认并可直接追加，行为信号或 Agent 推断产生的偏好、职业假设和程序性策略必须先进入记忆收件箱；每次生效或撤销都保留变化前后、来源、理由、影响和取代关系。该决策取代 ADR-0002，并覆盖 ADR-0011 中允许自动写入推断偏好的表述，以增加条目修订与当前视图派生的复杂度，换取跨岗位不污染、逐项撤销、来源级联失效和下游材料过期判断。
