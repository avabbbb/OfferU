# 面试、简历与投递通过学习观察反哺使用者职业模型

OfferU 的 AI 面试、AI 简历优化、岗位研究和投递进展都必须产生带来源的学习观察，并由统一 Memory Service 评估其是否应更新使用者职业模型；业务模块不得直接改写其他模块或整体 Profile。学习观察晋升时继续遵守分层写权限：职业证据必须由使用者确认，求职偏好可以可见、可审计、可撤销地更新，职业假设独立保存并等待验证；简历改写的采纳/拒绝、面试回答表现和投递阶段结果可以改进策略与提示，但不能被自动改造成虚构经历。
