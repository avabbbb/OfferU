# 外部执行器工具权限限定到当前托管任务

OfferU 在创建托管执行会话时为其确定任务能力授权，只暴露当前可审计重任务所需的 Operation 和数据范围；外部 Coding Agent 不能发现或调用白名单之外的 OfferU 能力，也不能通过通用 API、任意 shell 或 Skill 指令扩大权限。所有调用继续经过 Operation Registry，外部执行器只能提交候选结果和待确认动作，不能直接写入职业事实或正式求职状态。选择任务级白名单而不是完整只读工具箱，是为了让最小授权成为可执行约束，并避免无关职业数据进入外部 Agent 上下文。
